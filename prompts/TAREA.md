# Tarea: Mi prompt profesional 

## Funcionalidad elegida

Desarrollo de un módulo de **Registro de Clientes con Validación de Datos** en Java.

## Version 1: prompt basico 

```text
Hazme un programa en Java para registrar clientes.
```
## Version 2

```text
Actúa como un desarrollador Java Senior. Crea un programa en Java para un sistema de gestión comercial enfocado en el registro de clientes.
```

## Version 3: prompt final

```text
Actúa como un desarrollador Java Senior experto en Clean Code. Crea un programa en Java para un sistema de gestión comercial enfocado en el registro de clientes usando una clase llamada Cliente con los atributos id (int), nombre (String), dni (String) y email (String). Incluye métodos de validación para el dni (8 dígitos) y el email (debe contener '@'). No utilices librerías externas.

Usa este estilo para el constructor:
public Cliente(int id, String nombre, String dni, String email)

Explica primero las validaciones aplicadas y luego presenta el código Java completo.
```
